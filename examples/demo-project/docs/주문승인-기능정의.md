# ZDEMO0100 주문 승인 — 기능 정의 (데모용 가상 문서)

이 문서는 스킬의 "문서 조사" 단계를 보여 주기 위한 가상의 스펙이다.

## 화면

- 탭1 **주문 목록**: 주문 헤더와 총금액, 가장 최근 승인번호를 보여 준다. 행을 누르면 상세 화면에서 품목을 본다.
- 탭2 **승인 이력**: 주문별로 가장 최근 승인 건만 보여 준다.

## 기능

### 1. 주문 헤더

- 주문 테이블(ZTDEMO_ORDER)에 고객 이름을 붙여 조회한다.
- 화면용 BO는 `ZDEMO_R_ORDER`다.

### 2. 주문 품목 · 금액

- 품목 테이블(ZTDEMO_ITEM)을 조회한다.
- 총금액은 취소되지 않은 품목의 금액 합계다.

### 3. 승인 이력

- 승인 이력 테이블(ZTDEMO_APPR)에 승인번호 순으로 쌓인다.
- 한 주문에 승인 이력이 여러 건일 수 있고, 화면에는 가장 최근 건을 쓴다.
